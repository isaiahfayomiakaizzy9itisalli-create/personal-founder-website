# Founder website

A lightweight static personal profile, separate from the OrchestFlow product code. The site has no build step or JavaScript.

## Files

- `index.html` — page content
- `styles.css` — responsive layout and visual styling
- `assets/images/profile-photo.jpg` — founder portrait

## Preview

Open `index.html` in a browser.

## GitHub Pages

Suggested publishing source: `main` branch, `/ (root)`. The page entry file and assets are arranged for static publishing without a build step. Set the repository's Pages source to these values after the site files are uploaded.

The portrait has been supplied for the public personal site. Avoid adding contact details or other personal information that the owner has not approved for publication. Typography uses Google Fonts with local system fallbacks.
